# Projektvorgaben

Sky möchte seit dem 05.10.2026 alle künftig angelegten Softwareprojekte auf GitHub versionieren. Diese Vorgabe gilt auch für Folgeänderungen: Arbeit gilt erst als auf GitHub abgelegt, wenn der Commit im Zielrepository vorhanden ist.

Für die Minecraft-Mods ist `jsky0603/lmf` das vorhandene öffentliche Repository. Neue Mods als eigenständige Projekte in eigenen Ordnern ergänzen. Vorhandene Modprojekte nicht zusammenführen. Quellen, Anleitung, Beispielkonfiguration und passende Build-Dateien mitführen. Build-Ausgaben über einen eigenen, auf den Projektpfad beschränkten GitHub-Actions-Workflow bereitstellen.

Die GitHub-Vorgabe gilt als dauerhafter Arbeitsstandard. Für neu benötigte Repositories ist privat der Standard, solange keine andere Sichtbarkeit verlangt wird. Die Veröffentlichung eines neuen Projekts in einem öffentlichen Ziel muss durch die Benutzeranweisung oder eine passende Bestätigung gedeckt sein. Nach bestätigter Repository-Auswahl und Sichtbarkeit für gewöhnliche Folge-Commits nicht erneut nachfragen. Laufzeitfreigaben bleiben maßgeblich.

Zugangsdaten, echte Bot-Tokens, API-Schlüssel und persönliche Laufzeitdaten gehören nicht in Git. Ausschließlich leere oder harmlose Beispielwerte verwenden. Fremde Änderungen erhalten, keinen Force-Push verwenden. Branch-Regeln des jeweiligen Repositories beachten.
